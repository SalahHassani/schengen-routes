# Brand Guidelines — SchengeN Routes

## Brand Identity

- **Brand Name**: SchengeN Routes _(the capital `N` in `SchengeN` is intentional)_
- **Tagline**: Your Gateway to Europe
- **Service Line**: Study • Travel • Explore
- **Brand Constants File**: `src/lib/constants.ts`
- **Logo Rule**: Always use the approved original SchengeN Routes logo asset (`public/assets/brand/logo-primary.png`) via `<BrandLogo />` (`src/components/ui/brand-logo.tsx`). Never redraw, replace, or generate an AI substitute.

## Four-Colour Design System

| Colour            | HEX       | Target Distribution | Usage                                                                     |
| :---------------- | :-------- | :------------------ | :------------------------------------------------------------------------ |
| **White**         | `#FFFFFF` | ~50%                | Page backgrounds, cards, reading surfaces, negative space                 |
| **Deep Navy**     | `#102A43` | ~30%                | Primary headings, navigation, primary buttons, footer, dark hero sections |
| **European Blue** | `#174A78` | ~10%                | Secondary buttons, links, active states, interactive badges, icons        |
| **Gold**          | `#C5A15A` | ~10%                | Restrained highlights, accent rules, premium badges, key icons            |

_Note: Neutral slate greys (`src/styles/tokens.ts`) are permitted strictly as supporting UI neutrals. Gold must never be used for small body text on white backgrounds._

## Typography & Components

- **Headings**: `Manrope` (SemiBold / Bold / ExtraBold)
- **Body Text**: `Inter` (Regular / Medium / SemiBold)
- **Buttons**: `Manrope SemiBold` (`8px` / `0.5rem` border radius)
- **Cards**: `14px` (`0.875rem`) border radius with subtle Deep Navy–tinted shadows and restrained borders
